# 🎲 Pig Game

A fun and interactive two-player dice game built with **HTML**, **CSS**, and **JavaScript**.

This project was part of my front-end learning journey, where I focused on improving my **DOM manipulation**, **event handling**, and **game logic** skills using vanilla JavaScript.

---

## 🕹️ How to Play
- The game has two players.
- On each turn, a player rolls the dice:
  - If the dice shows **2–6**, the number is added to the current score.
  - If the dice shows **1**, the player loses the current score, and it switches to the next player.
- A player can **“Hold”** to save their current score to the total.
- The first player to reach **100 points** wins the game! 🏆
